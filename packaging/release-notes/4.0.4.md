## omafish 4.0.4

This release catches omafish up with Omarchy 4.0.4 and makes it a home for more than a port. good-git-abbr is merged in, there are new tmux profiles, and `omarchy` gets tab completion in fish.

### New

- **Reopen your tmux windows after a reboot with `tdp`.** `tdp save` lists the current session's windows with every one selected. Press TAB to drop any you don't want, then name the profile. `tdp <name>` brings them all back as `tdl` layouts, from inside tmux or from a fresh terminal. The folders don't need to share a parent, unlike `tdlm`.

  ![tdp save picking five of six windows](https://github.com/crmne/omafish/releases/download/4.0.4/tdp-save.png)

- **Git abbreviations are built in.** The 55 abbreviations from good-git-abbr (`gst`, `gco`, `gcb`, `gP`, `gup`, and the rest) now ship with omafish, and `gabbr` lists them. Omarchy's `g`, `gcm`, `gcam`, and `gcad` are now abbreviations too, so they expand to the full git command before you run it.
- **Tab completion for `omarchy`.** Subcommands complete at every level, and so do argument values such as `on`, `off`, and `toggle`.

  ![omarchy bluetooth power completing its values](https://github.com/crmne/omafish/releases/download/4.0.4/omarchy-complete.png)

- **Everything Omarchy 4.0.4 added to its shell:**
  - `tds`, a 2x2 layout with editor, diff watch, terminal, and opencode.
  - The herdr layouts: `hdl`, `hdlm`, `hds`, `hsl`.
  - `ic`, `ix`, `icx` to open `tdl` with opencode, claude, or both.
  - `a` (omarchy-agent), `cy` (codex), `h` (herdr), `mup`.
  - `sff` to pick a file and scp it.
  - `rsw`, `lsw`, `dsw` to rsync a folder whenever it changes.
  - An `ssh` wrapper that resets the terminal and reconnects when a session drops.
  - Man pages colored with bat.
  - Git worktree helpers, named `gwa` and `gwd` here because `ga` and `gd` are `git add` and `git diff`.
- **`try` is back, without the startup cost.** It loads the first time you run it.

### Fixed

- **`cd -`, `prevd`, `nextd`, `cdh`, and Alt+Left/Right work again.** omafish's zoxide `cd` replaced fish's own `cd`, which is where fish keeps directory history. `cd` now builds on fish's version, and only in interactive shells, so scripts get plain `cd`.
- **`cd` with options or several arguments** behaves like the normal `cd` instead of going to zoxide.

### Upgrading

- **If you use good-git-abbr, remove it first:** `fisher remove crmne/good-git-abbr.fish`. Both plugins ship `gabbr`, and Fisher won't update a plugin whose files already exist. good-git-abbr is now archived.
- `ga` and `gd` are `git add` and `git diff`. Omarchy's worktree helpers are `gwa` and `gwd`.
- `c` runs `opencode --auto`, matching Omarchy. `cx` runs `claude --dangerously-skip-permissions` and `cy` runs `codex --yolo`. Omarchy's own `cx` and `cy` now use auto-approval modes, but omafish keeps skipping permission prompts.
- The image and video helpers stay in omafish, even though Omarchy moved them into `omarchy-transcode`.

### Known limitations

- The herdr layouts have not been run against a live herdr session yet. Please open an issue if one misbehaves.
- `tdp` restores folders and the `tdl` layout, not what was running in each pane.
