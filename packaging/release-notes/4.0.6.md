## omafish 4.0.6

This release fixes `cd` failing on some machines, and makes the tmux layout commands work inside herdr.

### Fixed

- **`cd` works again everywhere.** On some machines every `cd` failed with "The expanded command is a keyword". It happened when omafish could not keep a copy of fish's own `cd`, either because fish is installed outside `/usr/share/fish` or because an old omafish `cd.fish` was still in `~/.config/fish/functions`. omafish now recognizes fish's `cd` wherever fish is installed, and falls back to the builtin `cd` correctly when it can't.

### New

- **The tmux layout commands work inside herdr.** In herdr, `tdl`, `tdlm`, `tds`, and `tsl` run `hdl`, `hdlm`, `hds`, and `hsl`, so `ic`, `ix`, and `icx` work there too.

### Upgrading

- If `cd` broke after updating to 4.0.4 or 4.0.5, also check for a leftover `~/.config/fish/functions/cd.fish` from an older omafish and delete it. Fisher removes the files it installed, but a copy restored by a dotfiles manager or by hand stays behind and replaces omafish's `cd`.
